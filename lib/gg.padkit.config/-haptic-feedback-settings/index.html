HapticFeedbackSettings

data class HapticFeedbackSettings(val intensity: Float = 1.0f, val discreteDirections: DirectionHapticFeedback = DirectionHapticFeedback.CHANGE, val continuousDirections: Boolean = true, val coalesceEffects: Boolean = true, val excludedControlIds: Set<Id> = emptySet())

Portable feedback preferences. Intensity is normalized, with zero explicitly silent. Devices without amplitude control use their default amplitude for nonzero requests. Feedback follows logical input, including simulated input. Excluded IDs never request feedback.
